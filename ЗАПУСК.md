# Как запустить распознавание у себя

Нужен Python 3.10 или новее (Windows, macOS или Linux). Интернет нужен только для установки библиотек; модель 1.3.1 уже лежит в архиве (`care_label_recognition/models/`; прежние — в `models/v1.3.0/` и `models/v1.2.1/`) и работает без сети и без видеокарты.

## 1. Установка (один раз)

Распакуйте архив `care_label_recognition.zip` и откройте терминал в распакованной папке `care_label_recognition` (там, где лежит этот файл).

**Windows** (PowerShell или «Командная строка»):
```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Ставятся три библиотеки: numpy, opencv-python-headless и Pillow.

## 2. Запуск на папке с фото

Сложите фото ярлыков (JPG, PNG, WEBP) в одну папку, например `C:\Users\Катя\Desktop\ярлыки`, и выполните:

```
python run_folder.py "C:\Users\Катя\Desktop\ярлыки"
```

На macOS: `python run_folder.py ~/Desktop/ярлыки`

Рядом появится папка `ярлыки_results`. В ней:
- `<фото>_annotated.jpg` — фото с пронумерованными рамками и расшифровкой под ним. Зелёный значит «распознано», оранжевый — «неуверенно».
- `<фото>.json` — полный ответ модуля.
- `summary.csv` — все символы всех фото одной таблицей (открывается в Excel).

Другую папку для результатов можно задать так: `python run_folder.py ПАПКА --out ПАПКА_РЕЗУЛЬТАТОВ`.

Проверить, что всё работает, можно на готовых примерах: `python run_folder.py examples/input`.

## 3. Одно фото и JSON в консоль

```
python recognize.py фото.jpg
```

`--debug` дополнительно сохранит промежуточные картинки (найденный ярлык, кандидаты, кропы) в `debug_output/`.

## Советы по съёмке

- Ярлык должен занимать заметную часть кадра. Символы меньше ~30 px по высоте модель почти не находит, поэтому лучше снимать ближе.
- Нужен ровный свет без бликов, кадр не должен быть смазан.
- Время работы — около 1–4 секунд на фото на обычном ноутбуке.
