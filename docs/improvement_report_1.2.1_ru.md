# Отчёт об исправлении 1.2.1 — слабоконтрастный символ на ярлыке

Дата: 24.10.2026

## Исправленный случай

На фото `my_labels/photo_2026-10-04_17-08-37.jpg` детектор находил четыре значка из пяти. Пропущенным был четвёртый слева значок — утюг с одной точкой (`iron_low`, глажение при низкой температуре). Он терялся до этапа классификации: основная бинаризация фрагментировала тонкий контур на текстурной ткани.

В `care_label_recognition/symbol_detector.py` добавлен резервный проход с адаптивным порогом. Его кандидаты рассматриваются только в свободном промежутке между уже найденными символами, при совпадении горизонтального ряда и близком размере значков. Это ограничивает вероятность принять текст или фактуру ткани за дополнительный символ.

## Повторная проверка `My Labels`

| Фото | Результат | Символы | Неуверенные |
|---|---|---:|---:|
| `photo_2026-10-04_17-08-37 (2).jpg` | success | 4/4 | 0 |
| `photo_2026-10-04_17-08-37 (3).jpg` | success | 5/5 | 0 |
| `photo_2026-10-04_17-08-37.jpg` | success | 5/5 | 0 |

На проблемном фото распознаны: `wash_30_gentle`, `bleach_no`, `dry_tumble_no`, `iron_low`, `pro_no`. Таким образом, все пять значков обнаружены в правильном порядке, включая ранее пропущенный `iron_low` (уверенность в сохранённом результате: 0.969).

В этой версии CNN не переобучалась: проблема была на этапе обнаружения областей, потому что символ не попадал к классификатору. Исправление сделано в детекторе, чтобы не маскировать сбой искусственным снижением порога уверенности. Веса классификатора остались теми же, что в версии 1.2.0.

## Внешние датасеты

Подготовлены `training/external_datasets.json`, `training/fetch_external_datasets.py`, `requirements-datasets.txt` и `docs/external_datasets.md`. В реестре собраны источники Roboflow, Kaggle и GitHub, указаны предполагаемые объёмы, классы, ссылки и ограничения лицензий/доступа; дубль-пересечения отмечены как возможная проблема.

Попытка скачать GitHub-архивы из этой среды не удалась из-за отсутствия разрешения DNS для `codeload.github.com`. Поэтому **новые внешние наборы не включены в ZIP и не использовались для обучения**. Скрипт загрузки добавлен, чтобы забрать подходящие данные с компьютера с доступом к интернету. Некоторые наборы требуют ключ Roboflow, аккаунт/принятие условий Kaggle, а для источников без явной лицензии требуется ручная проверка прав. Небольшие наборы и наборы для детекции всего ярлыка не следует считать эквивалентом хорошо размеченного набора символов.

Успешная проверка данного фото не доказывает идеальную работу на всех реальных ярлыках; для этого нужна независимая тестовая коллекция, не пересекающаяся с обучающими данными.
